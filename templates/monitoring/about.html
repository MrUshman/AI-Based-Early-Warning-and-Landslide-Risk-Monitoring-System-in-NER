Problem Statement & Regional Vulnerability

India's North-East Region (comprising Arunachal Pradesh, Assam, Manipur, Meghalaya, Mizoram, Nagaland, Sikkim, and Tripura) constitutes one of the most landslide-susceptible geological zones on Earth. Characterized by steep young Himalayan tectonic thrusts, heavy annual rainfall exceeding 2,500mm, and extensive overburden weathering, key corridors such as NH-10 (Sikkim-Bengal link), NH-6 (Meghalaya-Assam-Barak Valley), and NH-29 (Nagaland) suffer routine catastrophic collapses during monsoon seasons.

Conventional monitoring relies on manual post-incident reporting, resulting in delayed evacuations and stranded traffic. This project implements an integrated IoT telemetry pipeline paired with a trained Random Forest Machine Learning classifier to predict slope failure hours in advance, allowing District Disaster Management Authorities (DDMA) to implement proactive closures and evacuations.

Multi-Tier System Architecture
1. Sensing Layer
Rain gauges, TDR soil moisture probes, tiltmeters, accelerometers.
2. Ingestion API
Django REST endpoint (/api/readings/) + Open-Meteo live sync.
3. AI Classifier
Random Forest (120 trees) evaluating 7 geotechnical features.
4. Action & GIS
Leaflet GIS spatial map + automated early warning dispatch.
Feature Weightings & Physics Integration
Feature Parameter Unit / Scale Physical Impact on Factor of Safety (FS)
Rainfall (24h & 72h) Millimeters (mm) Pore-water pressure escalation reducing effective soil shear resistance.
Volumetric Soil Moisture Percentage (%) Approaching soil liquid limit; saturation >80% triggers plastic slip.
Slope Angle Degrees (0° - 90°) Direct gravitational shear stress component ($\tau = \gamma h \sin\beta\cos\beta$).
Ground Vibration Seismic index (0 - 10) Dynamic horizontal accelerations that overcome static frictional cohesion.
Geotechnical Soil Type Clay, Silt, Loam, Rocky Internal friction angle ($\phi$) and cohesion ($c$) variations.
Technology Stack
  • Backend: Python 3, Django 5.1
  • AI / ML: Scikit-Learn (Random Forest)
  • Numerical Processing: NumPy, Pandas
  • Mapping GIS: Leaflet.js, OpenStreetMap
  • Frontend: Bootstrap 5.3, Chart.js 4.4
  • Weather Source: Open-Meteo REST API
  • Storage: SQLite (Development) / PostgreSQL
